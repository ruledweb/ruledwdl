---

## 1. Overview

The **`REGISTRY v1.0`** specification defines basic key-value mappings of class-name tokens to flat attribute objects or utility strings.

---

## 2. Schema Structure (v1.0)

A valid `REGISTRY v1.0` dictionary maps bare class-name component IDs to strings or attribute objects:

```json
{
  "$version": "1.0",
  "card": {
    "class": "p-4 bg-white rounded-lg shadow-sm"
  },
  "title": {
    "class": "text-xl font-bold text-gray-900",
    "text": "${heading}"
  },
  "button": "px-4 py-2 bg-blue-600 text-white rounded"
}
```

---

## 3. Specification Rules

1. **Component Keys**: Keys must be bare identifier strings (e.g. `"card"`, `"button"`). Dots (`.`) are not allowed in REGISTRY keys.
2. **Flat Attributes**: Values are merged onto matching element nodes when the element class matches the registry key.
3. **Data Binding**: String values support `${var}` data interpolation.
