## 1. Overview

The **`COMPONENTS v1.0`** specification defines baseline WDL Layers DOM hierarchy expressions and component ID reference lookup logic.

---

## 2. Schema Structure (v1.0)

```json
{
  "COMPONENTS": [
    {
      "$version": "1.0",
      "layers": "section.hero>div.container>h1.title+p.subtitle<div.banner",
      "attr": {
        ".title": { "text": "${heading}" }
      }
    },
    {
      "component": "card",
      "data_overrides": { "title": "Card 1" }
    }
  ]
}
```

---

## 3. WDL Layers Grammar v1.0

* `tag.semantic_id`: Node definition (strictly 1 semantic class ID).
* `>`: Descend 1 level.
* `+`: Add sibling at current level.
* `<`: De-indent 1 parent level (`<<` climbs 2 levels).
* `*N`: Numeric multiplier (`li.item*3`).
* `*items`: Data loop array iteration (`li.post*posts`).
