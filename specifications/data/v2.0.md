> **Status**: Active Standard

## 1. Overview

The **`DATA v2.0`** specification manages state, dynamic data loops, head element injections, and design token cascades for WDL page rendering.

---

## 2. Schema Structure (v2.0)

`DATA` is a state dictionary:

```json
{
  "$version": "2.0",
  "page_title": "Product Overview",
  "items": [
    { "title": "Feature 1", "desc": "Fast ESM runtime" },
    { "title": "Feature 2", "desc": "Zero framework lock-in" }
  ],
  "__design_tokens": ":root { --brand-primary: #0284c7; }",
  "__brand_tokens": ":root { --brand-primary: #0369a1; }",
  "__head": "<meta name=\"theme-color\" content=\"#0284c7\">"
}
```

---

## 3. Specification Rules & Reserved Keys

| Key / Syntax | Description |
| :--- | :--- |
| **`${var}` or `${obj.key}`** | String interpolation resolved dynamically during element rendering. |
| **`__design_tokens`** | Base CSS variable tokens injected inside `<style data-wdl="design-tokens">`. |
| **`__brand_tokens`** | Brand-specific CSS variable overrides injected inside `<style data-wdl="brand-tokens">` (wins cascade over design tokens). |
| **`__head`** | Raw HTML or array of string tags injected into the document `<head>`. |
| **Array Data Loops** | Data loop keys (e.g. `posts`) MUST contain arrays of objects (e.g. `[{"title": "Item"}]`). Array of primitives is strictly forbidden. |
