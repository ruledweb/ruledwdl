# WDL Specification: DATA (v2.0)

> **Specification Version**: `2.0`  
> **Status**: Active Standard  
> **Maintained in**: [`specifications/data/v2.0.md`](file:///home/pradeep/cloudflare/workers/wdl-core/specifications/data/v2.0.md)

---

## 1. Overview

The **`DATA v2.0`** specification manages state, dynamic data loops, head element injections, and design token cascades for WDL page rendering.

---

## 2. Envelope

Core does not publish a JSON Schema for `DATA`. The fields inside `DATA` belong to the page or the component. The author, or the AI writing that page, supplies a JSON Schema Draft-07 document named `DATA_SCHEMA` beside `DATA`. Core stores that document and does not validate it.

Core reads only the keys in the table below. Every other key is author data. A loop value is an array of objects.

```json
{
  "$version": "2.0",
  "__design_tokens": ":root { --brand-primary: #0284c7; }",
  "__brand_tokens": ":root { --brand-primary: #0369a1; }",
  "__head": "<meta name=\"theme-color\" content=\"#0284c7\">",
  "__seo": { "title": "Product Overview", "description": "Edge runtime" }
}
```

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "heading": { "type": "string" }
  },
  "required": ["heading"]
}
```

The second document is an author `DATA_SCHEMA`. `heading` is that author's field. It is not a core field.

---

## 3. Specification Rules & Reserved Keys

| Key / Syntax | Description |
| :--- | :--- |
| **`$version`** | Optional. `2.0` for this envelope. |
| **`${var}` or `${obj.key}`** | String interpolation resolved during element rendering. |
| **`__design_tokens`** | Base CSS variable tokens injected inside `<style data-wdl="design-tokens">`. |
| **`__brand_tokens`** | Brand CSS variable overrides injected inside `<style data-wdl="brand-tokens">`. These win over design tokens. |
| **`__head`** | Raw HTML or an array of tags injected into the document `<head>`. |
| **`__seo`** | Object passed to the page shell for title, description, canonical, robots, and Open Graph tags. |
| **`DATA_SCHEMA`** | Author-supplied Draft-07 JSON Schema for this page or component's own fields. It sits beside `DATA`. It is not a core schema. |
| **Array Data Loops** | A loop value is an array of objects, such as `[{"title": "Item"}]`. |
