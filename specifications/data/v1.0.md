> **Status**: Legacy Standard (Frozen)

---

## 1. Overview

The **`DATA v1.0`** specification defines basic state dictionaries, template variable interpolation, and simple array iteration payload requirements.

---

## 2. Schema Structure (v1.0)

```json
{
  "DATA": {
    "$version": "1.0",
    "name": "World",
    "posts": [
      { "title": "First Post" },
      { "title": "Second Post" }
    ]
  }
}
```

---

## 3. Specification Rules

1. **`${var}` String Binding**: Interpolates matching keys from `DATA`.
2. **Array Loops**: Loop keys (e.g. `posts`) MUST contain arrays of objects (primitives strictly forbidden).
